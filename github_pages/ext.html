WebTCP Extension Handbook

A complete reference for building, loading, and distributing extensions for WebTCP.

Overview Languages Structure API Reference UI Widgets Audio & IQ Examples Themes

Overview

Extensions extend WebTCP with custom decoders, visualizers, analyzers, and tools. They execute on the host machine inside a restricted sandbox and communicate with the browser interface through a straightforward message passing API.

Extensions can:

  • Receive live audio samples and decoded IQ data
  • Render custom panels containing text fields, sliders, toggles, images, and buttons
  • Write files (images, logs, etc) to a designated data directory on the server
  • Display popups and toast notifications in the browser
  • Respond to UI events in real time
Security notice: Extentions don't have to be approved officially, Load extensions only from authors you trust.

Supported Languages

WebTCP supports extensions written in four languages. Each language is executed by its own secure runner process:

ExtensionLanguageNotes
.py Python 3.9+ NumPy/SciPy access. This is Recommended for DSP work.
.lua Lua 5.4 This is Lightweight with fast startup. This can Suitable for simple decoders.
.js Node.js 18+ Known for native async support, and JSON handling.
.cpp C++17 High Performance.
Python is the recommended choice for most extensions since other languages have not been tested fully.

Extension Structure in Python

The Python extension consists of a single file that subclasses Extension from the sdr_ext module:

from sdr_ext import Extension, ui

class MyDecoder(Extension):
    name = "My Decoder"
    description = "lorem ipsum dolor sit amet consectetur adipiscing."
    author = "Your Name"
    version = "1.0"

    def on_load(self):
        # Called once when the extension starts.
        # Initialize state and define the panel UI here.
        self.set_panel([
            ui.Label("status", "Ready."),
            ui.Text("out", "Output", lines=6),
            ui.Button("clear", "Clear"),
        ], title="My Decoder", width=400)

    def on_audio(self, samples, rate):
        # Called with each chunk of float64 audio at 48000 Hz.
        pass

    def on_tick(self):
        # Called approximately every 500 ms.
        # Suitable for updating status labels.
        pass

    def on_event(self, widget_id, value):
        # Called when the user interacts with a UI widget.
        if widget_id == "clear":
            self.set_text("out", "")

API Reference

Extension methods

MethodDescription
self.set_panel(widgets, title, width) Creates or replaces the floating panel. Call from on_load.
self.set_label(id, text) Updates the text of a Label widget.
self.set_text(id, text) Replaces all text in a Text widget.
self.append_text(id, text) Appends text to a Text widget (auto-scrolls).
self.set_image(id, array) Updates an Image widget. Accepts a uint8 NumPy array of shape (H, W) or (H, W, 3).
self.set_value(id, value) Sets the value of a Slider, Toggle, or Select widget.
self.popup(title, text) Displays a modal popup in the browser.
self.save_image(filename, array) Saves a PNG to the server data directory. Returns the file path.
self.data_dir Path to the server-side directory available for file storage.
self.radio Read-only dictionary containing: freq, center, mode, bandwidth, sample_rate, audio_rate, squelch_open, agc.

Overrideable callbacks

CallbackSignatureDescription
on_load (self) Called when the extension starts. Initialize state and UI.
on_audio (self, samples: np.ndarray, rate: int) New audio chunk. Samples are float64, mono, at rate Hz (typically 48000).
on_iq (self, iq: np.ndarray, rate: float) Raw channel IQ data (complex64) at the decimated rate. Enable with self.request_iq(True).
on_tick (self) Periodic callback at approximately 500 ms intervals.
on_event (self, widget_id: str, value) Called when the user interacts with a UI widget.
on_unload (self) Called when the extension is stopping. Perform cleanup here.

UI Widgets

from sdr_ext import ui

ui.Label("id", "initial text")
ui.Text("id", "Label shown above box", lines=8)
ui.Slider("id", "Label", min, max, default, step=1)
ui.Toggle("id", "Label", default_bool)
ui.Select("id", "Label", ["option1", "option2"], default)
ui.Button("id", "Button label text")
ui.Image("id", "Caption", clickable=False)

When clickable=True is set on an Image widget, on_event receives value = {"x": 0..1, "y": 0..1} representing the fractional click coordinates.

Audio & IQ Access

The on_audio callback delivers post-demodulation audio that has already passed through AGC, filters, and squelch. Samples are float64 values approximately in the range -1..1, mono, at 48000 Hz.

To receive raw pre-demodulation IQ data, call self.request_iq(True) inside on_load and implement on_iq(self, iq, rate). The IQ array is complex64 at the channel’s decimated sample rate.

Examples

Minimal audio level meter

import numpy as np
from sdr_ext import Extension, ui

class LevelMeter(Extension):
    name = "Level Meter"
    description = "Displays the RMS level of the received audio."
    author = "Example"
    version = "1.0"

    def on_load(self):
        self.rms = 0.0
        self.set_panel(
            [ui.Label("lvl", "0.0 dBFS")],
            title="Level Meter",
            width=240
        )

    def on_audio(self, x, rate):
        rms = float(np.sqrt(np.mean(x ** 2)))
        self.rms = 0.8 * self.rms + 0.2 * rms

    def on_tick(self):
        db = 20 * np.log10(max(self.rms, 1e-9))
        self.set_label("lvl", f"{db:.1f} dBFS")

Simple DTMF tone detector

import numpy as np
from sdr_ext import Extension, ui

ROW = [697, 770, 852, 941]
COL = [1209, 1336, 1477, 1633]
KEYS = [
    ["1", "2", "3", "A"],
    ["4", "5", "6", "B"],
    ["7", "8", "9", "C"],
    ["*", "0", "#", "D"],
]

class DTMFDecoder(Extension):
    name = "DTMF Decoder"
    description = "Detects DTMF tones"
    author = "Example"
    version = "1.0"

    def on_load(self):
        self.last = ""
        self.set_panel([
            ui.Label("key", "Listening..."),
            ui.Text("out", "Digits", lines=4),
        ], title="DTMF", width=280)

    def on_audio(self, x, rate):
        N = min(len(x), 2048)
        spec = np.abs(np.fft.rfft(x[:N], N))
        freqs = np.fft.rfftfreq(N, 1 / rate)

        def peak(f):
            return float(spec[np.argmin(np.abs(freqs - f))])

        r = max(range(4), key=lambda i: peak(ROW[i]))
        c = max(range(4), key=lambda i: peak(COL[i]))
        digit = KEYS[r][c]

        if peak(ROW[r]) > 200 and peak(COL[c]) > 200:
            if digit != self.last:
                self.last = digit
                self.append_text("out", digit)
                self.set_label("key", f"Key: {digit}")
        else:
            self.last = ""

Themes (.tcptheme)

WebTCP interface colors can be customized with .tcptheme files. Place the files in any accessible location and load them from the Themes section in settings.

Gradient theme

gradient:true
color1_FF0F7B
color2_F89B29
color3_FFD200

Single color theme

gradient:false
color1_292F56

Follow system light/dark mode

gradient:false
systemcolors:true

Colors are specified as six digit HEX values without a leading #.
